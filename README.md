# NGO Research & Data Collection 🇮🇳

## 📌 Project Overview

This project focuses on researching and collecting information about 10 Non-Governmental Organizations (NGOs) operating across different social sectors in India.

This project was completed as **Task 1 of my Data Analytics Internship at InAmigos Foundation**.

## 🎯 Objective

To understand how NGOs operate across different social sectors and develop practical skills in data collection, online research, data organization, and documentation.

## 📊 Dataset Information

The dataset contains information about 10 Indian NGOs, covering the following fields:

* NGO Name
* Official Website
* Social Sector
* Area of Work
* Headquarters
* Key Initiatives and Programs
* Research Sources

## 🌍 Social Sectors Covered

* Education
* Healthcare
* Child Welfare
* Women Empowerment
* Animal Welfare
* Environmental Conservation
* Rural Development

## 🛠️ Tools Used

* Microsoft Excel
* Google Search
* Official NGO Websites
* Data Collection and Organization Techniques

## 📁 Project Files

`NGO Research Data.xlsx` – Main dataset containing research information about 10 NGOs.
